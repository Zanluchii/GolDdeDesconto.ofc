# Gol de Desconto ⚽⚡

Site de ofertas de afiliados com foco em **Esportes** e **Tecnologia**. É um site estático (HTML, CSS e JS puros) que lê os produtos de uma planilha do Google Sheets publicada como CSV.

👉 **Leia o manual em português: [LEIA-ME.md](LEIA-ME.md)**

Para testar no computador:

```bash
python3 -m http.server 8000
```

Depois, abra http://localhost:8000.
